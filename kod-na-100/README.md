# КОД НА 100 — сайт онлайн-подготовки к ОГЭ и ЕГЭ по информатике

Адаптивный статический сайт в тёмном минималистичном стиле. Без сборки и платных библиотек: HTML, CSS и JavaScript.

## Перед публикацией

1. Открой `script.js`.
2. Найди строку:
   `const TELEGRAM_USERNAME = "YOUR_TELEGRAM_USERNAME";`
3. Замени `YOUR_TELEGRAM_USERNAME` на свой Telegram username без `@`.
   Например: `const TELEGRAM_USERNAME = "myusername";`
4. Если не хочешь использовать Telegram, измени обработчик формы в конце `script.js` и поставь свой реальный контакт.
5. Проверь цену занятия и контактные данные. Сейчас на сайте не указаны выдуманные цены, квалификации, отзывы и результаты учеников.

## Самый простой бесплатный запуск: Netlify Drop

1. Распакуй ZIP на компьютере.
2. Открой https://app.netlify.com/drop
3. Если сервис предлагает войти или создать аккаунт, сделай это бесплатно.
4. Перетащи папку `kod-na-100` в область загрузки. Если папка не принимается, перетащи ZIP после распаковки или выбери папку `kod-na-100` через файловый менеджер.
5. Дождись публикации и открой выданную ссылку.
6. Проверь сайт с телефона и отправку тестовой заявки.

Условия и доступность бесплатного тарифа могут меняться. Сайт не содержит серверной части: форма открывает Telegram с подготовленным сообщением и не хранит данные на сайте.

## Альтернатива: GitHub Pages

1. Создай репозиторий на https://github.com/new (можно публичный).
2. Загрузи `index.html`, `style.css`, `script.js` и `README.md` в корень репозитория.
3. В настройках репозитория открой **Settings → Pages**.
4. В разделе Build and deployment выбери **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем **Save**.
5. После публикации GitHub покажет адрес сайта в разделе Pages.

## Структура

- `index.html` — содержание сайта
- `style.css` — дизайн, адаптивность и анимации
- `script.js` — меню, анимации появления, форма заявки
- `README.md` — инструкции
